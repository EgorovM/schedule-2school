# Расписание — МБОУ «Нюрбинская СОШ №2 им. М. С. Егорова»

Два не связанных между собой продукта в одной папке:

| Что | Где | Для кого |
|---|---|---|
| Сайт школы (одна страница) | `index.html` | родители, ученики |
| Инструмент составления расписания | `raspisanie/` | заместитель директора по УВР |

## Инструмент расписания

### Запуск

```bash
python3 -m raspisanie                       # откроет http://127.0.0.1:8770
python3 -m raspisanie --check               # только проверить и вывести список нарушений
python3 -m raspisanie --import "путь/расписание 26-27.xlsx"   # перечитать рабочий файл
```

Нужен Python 3.10+ и `openpyxl` (только для импорта и выгрузки в Excel):
`pip3 install openpyxl`. Больше никаких зависимостей нет: сервер на стандартной
библиотеке, интерфейс — обычная страница без сборки.

### Что он делает

**Расписание.** Сетка по классам: день × урок, у каждого урока балл трудности и
учитель. Урок перетаскивается мышью — в пустой слот переносится, в занятый
меняется местами со стоящим там уроком. Над сеткой — сумма баллов за каждый день
и её доля от недели рядом с нормой.

**Учителя.** Недельная сетка одного педагога, его нагрузка и окна.

**Проверки.** Всё, что расходится с нормативом, с указанием пункта документа:

- предельная недельная нагрузка (СанПиН 1.2.3685-21, табл. 6.6);
- число уроков в день, включая правило «пять уроков один раз в неделю»;
- распределение трудности по дням недели (МР 2.4.0331-23, оба варианта);
- самый трудный предмет дня стоит первым или последним уроком;
- сдвоенные уроки в 1—4 классах;
- один предмет три раза за день;
- учитель в двух классах одновременно, кабинет занят дважды, окна;
- предметы, для которых балл трудности не задан.

Внеурочная деятельность (ВУД) в предельную аудиторную нагрузку не входит и
считается отдельно.

**Замены.** Отмечаете отсутствующего на дату — инструмент показывает его уроки и
для каждого подбирает, кто свободен в этот час: сначала учителя того же
предмета, затем остальные по возрастанию дневной нагрузки. Замены пишутся в
`data/substitutions.json`. Кнопка «Печать листа» даёт лист на день.

**Баллы.** Таблица трудности. По умолчанию — официальные значения СанПиН
(табл. 6.9 для 1—4, 6.10 для 5—9, 6.11 для 10—11). Своё значение в ячейке
перекрывает норматив и сохраняется в `data/scores.json`.

### Данные

```
data/schedule.json        рабочее расписание (правится через интерфейс)
data/substitutions.json   отсутствия и замены
data/scores.json          свои баллы трудности, перекрывают СанПиН
data/backups/             копия перед каждым изменением, хранится 40 последних
```

Импорт берёт лист **«РАСП С БАЛЛ»** (5—11 классы) и **«расписание нач классы»**
(1—4). Лист «РАСП БЕЗ БАЛЛОВ» не используется: в нём потерян класс 10в, сдвинуты
кабинеты и другие звонки.

### Чего он пока не делает

Не составляет расписание с нуля. Сейчас это редактор с проверками: берёт готовое
расписание, показывает нарушения и помогает их разводить. Автоподбор — следующий шаг.

### Откуда берутся учителя

В расписании 26/27 расстановки учителей нет — она есть только в 1—4 классах, где
номер педагога стоит перед названием предмета. Для 5—11 классов учителя
назначаются в интерфейсе: клик по уроку, затем выбор. Подсказка «вёл в прошлом
году» строится по листу «прием» — это расстановка другого года, поэтому она
именно подсказка, а не готовый ответ.

## Нормативные источники

- СанПиН 1.2.3685-21, гл. VI — табл. 6.6 (режим), 6.9—6.11 (шкалы трудности)
- СП 2.4.3648-20 — требования к организации учебного дня
- МР 2.4.0331-23 (Роспотребнадзор, 10.11.2023) — распределение трудности по дням недели

Все значения собраны в `raspisanie/sanpin.py`, каждое подписано источником.
